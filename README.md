# chess4p

Шахматы на четверых (4-player chess, FFA) с нейросетевым ботом.

## Состав

- `game/` — ядро игры на Rust: доска, генерация ходов, состояние, PGN-загрузчик, Zobrist-хэши, кодировка входа нейросети (256 плоскостей 14×14).
- `pyo3-bindings/` — Python-биндинги `chess4p_ai` (для selfplay и скриптов в `bot/`).
- `gui/` — **нативное окно (egui)**: играйте сами, назначайте ботов (0–4), лаунчер скриптов `bot/`.
- `bot/` — экранный бот для игры на chess.com (распознавание доски, калибровка, скачивание датасетов).
- `server/` — обучение (Kaggle): train.py, selfplay, model_utils.
- `training/` — модель, MCTS, replay buffer, интеграционные тесты.
- `scripts/` — утилиты: экспорт ONNX, экспорт PGN в GIF/JSON.

## Сборка и запуск GUI

```bat
cargo run --release -p chess4p-gui
```

Требуется (один раз):
1. **ONNX Runtime DLL**: папка `gui/ort_runtime/` с `onnxruntime.dll` + `DirectML.dll`.
   Проще всего — поставить pip-пакет `onnxruntime-directml` и скопировать
   `.../site-packages/onnxruntime/capi/*.dll` в `gui/ort_runtime/`.
2. **Модель**: сконвертируйте веса:
   ```bat
   python scripts\export_onnx.py C:\chess4p\bot\model.pt
   ```
   Полученные `model.onnx` (+ `model.onnx.data`, если появится) положите:
   - рядом с exe, или
   - в папку запуска (`gui/`), или
   - укажите путь во вкладке «⚙ Настройки».

## Как играть

- Перед партией каждому из 4 игроков назначьте **👤 Человек** или **🤖 Бот**
  (0–4 бота; 4 бота = режим наблюдения).
- Количество MCTS-симуляций настраивается для каждого бота (128/400/1600 или своё).
- Ходы — клик по фигуре, клик по клетке; легальные ходы подсвечиваются.
- Загрузка PGN, сохранение/загрузка JSON, история ходов с просмотром.
- Вкладка «📜 Скрипты» — запуск скриптов из `bot/` (калибровка, шаблоны,
  скачивание партий, selfplay-утилиты) с выводом в консоль.
