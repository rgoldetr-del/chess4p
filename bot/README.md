# Chess4P Screen Bot

Бот, который играет в 4-player chess через захват экрана и управление мышью. Интегрируется с существующим AI (MCTS + нейросеть).

## 🏗️ Архитектура

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌──────────────┐
│  Скриншот   │ ──▶ │ Распознавание│ ──▶ │  Ваш движок │ ──▶ │  Движение    │
│  экрана     │     │  доски (CV)  │     │  MCTS + NN  │     │  мыши        │
└─────────────┘     └──────────────┘     └─────────────┘     └──────────────┘
```

## 📦 Установка

```bash
cd /workspace/bot
pip install -r requirements.txt
```

### Зависимости:
- **mss** или **dxcam** (Windows) — захват экрана
- **opencv-python** — распознавание доски
- **pyautogui** или **pynput** — управление мышью
- **torch, numpy** — уже установлены для training

## 🚀 Быстрый старт

### 1. Калибровка позиции доски

```bash
python screen_bot.py --calibrate
```

Бот попросит вас позиционировать мышь в верхний-левый и нижний-правый углы доски для определения её положения и размера клеток.

### 2. Запуск игры

```bash
# Игра за красных (ходит первым)
python screen_bot.py --color 0

# Игра за синих
python screen_bot.py --color 1

# Игра за жёлтых
python screen_bot.py --color 2

# Игра за зелёных
python screen_bot.py --color 3
```

### 3. Настройка параметров

```bash
python screen_bot.py --color 0 --simulations 1600
```

Больше симуляций = сильнее игра, но дольше думает.

## ⚙️ Компоненты

### 1. Захват экрана (`ScreenCapture`)
- Использует **mss** (кроссплатформенно) или **dxcam** (Windows, быстрее)
- Захватывает область доски 14×14 клеток
- ~60 FPS без нагрузки на CPU

### 2. Распознавание доски (`BoardRecognizer`)
Два режима:

**А) Шаблонное распознавание** (по умолчанию):
- Template matching через OpenCV
- Требует шаблоны фигур в `bot/templates/`
- Быстро, но чувствительно к дизайну

**Б) CNN-классификатор** (TODO):
- Нейросеть на классификацию клеток
- Устойчивее к изменениям дизайна
- Требует обучения

### 3. Управление мышью (`MouseController`)
- Плавные движения с рандомизированной скоростью
- Кривые Безье для "человечности"
- Настройка задержек для скрытности

### 4. Синхронизация состояния (`GameStateSync`)
- Преобразует распознанную доску в тензор для нейросети
- 73 входных плана (как в AlphaZero)
- Интеграция с Rust GameState через PyO3 (опционально)

### 5. MCTS поиск (`think()`)
- Использует ваш существующий MCTS из `training/mcts.py`
- Интеграция с обученной моделью `model.pt`
- Поддержка температуры для разнообразия игры

## 🎨 Создание шаблонов фигур

Для шаблонного распознавания нужны PNG-файлы в `bot/templates/`:

```
bot/templates/
├── red_pawn.png
├── red_knight.png
├── red_bishop.png
├── red_rook.png
├── red_queen.png
├── red_king.png
├── blue_pawn.png
├── ... (ещё 18 файлов для blue, yellow, green)
└── empty.png
```

Размер каждого шаблона: 64×64 пикселя (или ваш cell_size).

### Как создать шаблоны:
1. Сделайте скриншот доски с фигурами
2. Вырежьте каждую фигуру в отдельный файл
3. Сохраните в `bot/templates/{color}_{piece}.png`

Или используйте скрипт для автоматического создания:

```bash
python bot/create_templates.py --screenshot board.png
```


### Координаты доски

Измените в `BotConfig`:
```python
board_top: int = 100      # Y координата верха доски
board_left: int = 200     # X координата левого края
board_width: int = 896    # 14 * 64
board_height: int = 896   # 14 * 64
```

Или используйте калибровку (`--calibrate`).

## 🛡️ Анти-детект

Для обхода анти-бот защиты:

1. **Рандомизация движений**:
```python
config.mouse_delay_min = 0.1
config.mouse_delay_max = 0.3
config.use_bezier = True
```

2. **Человеческие задержки**:
```python
delay_between_moves = random.uniform(1.5, 3.0)
```

3. **Кривые Безье** вместо прямых линий

4. **Вариативность выбора хода**:
```python
config.temperature = 0.7  # >0 для разнообразия
```

## 📊 Производительность

| Компонент | Время | Оптимизация |
|-----------|-------|-------------|
| Скриншот | 5-10ms | dxcam на Windows |
| Распознавание | 50-100ms | CNN быстрее template matching |
| MCTS (800 sim) | 500-2000ms | GPU, batch inference |
| Движение мыши | 200-500ms | Асинхронно |

**Итого**: ~1-3 секунды на ход
